# To-Do List Project  

This is a sleek and functional To-Do List application developed using **JavaScript**, **CSS**, and **HTML**. It helps you organize tasks efficiently with an intuitive interface and responsive design.  

### Features  
- Add, edit, and delete tasks with ease.  
- Mark tasks as complete to keep track of your progress.  
- Responsive and visually appealing layout for a seamless user experience.  
- Lightweight and fast, designed with clean and maintainable code.  

Feel free to explore, use, and enhance this project! Contributions and feedback are highly appreciated.
